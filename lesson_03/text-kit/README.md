# text-kit

Набор функций для работы с тестовыми данными, функции разбиты по пакетам и модулям
Программа демонстрирует работу со всеми функциями.

Внешних библиотек нет, нужен только Python 3.10 или новее.

## У меня получилась такая структура (сделал с помощью команды tree)

```
text-kit
│   README.md                 этот файл (что за программа, структура и как запускать)
│   
├───app                       пакет app
│   │   __init__.py           файл нужен для того что бы папка считалась пакетом 
│   │   main.py               главный модуль программы                           
│   │                                                                            
│   ├───services              пакет сервисов                                     
│   │       __init__.py       файл нужен для того что бы папка считалась пакетом 
│   │       statistics.py     модуль функций статистики
│   │       validation.py     модуль проверки
│   │                                                                            
│   └───utils                 пакет утилит                                       
│           __init__.py       файл нужен для того что бы папка считалась пакетом 
│           dates.py          модуль работа с датами
│           text.py           модуль работа с текстом
│           
└───tests
        test_dates.py        тесты модуля dates
        test_statistics.py   тесты модуля statistics
        test_text.py         тесты модуля text
        test_validation.py   тесты модуля validation
```

## Запуск

Команды выполняются из корня проекта — из папки, в которой лежит код программы.

```
python -m venv .venv
python -m app.main
python -m unittest discover -s tests -v
```

На Windows вместо `python` может потребоваться `py`, а окружение активируется
командой `.\.venv\Scripts\Activate.ps1`.
